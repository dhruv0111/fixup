## Evidence retention limitation and correction

The four original Phase 8 reports, saved JSON/logs, malformed-order evidence and backup manifests/archives remain. However, early reruns reused existing `.local/qa` screenshot names and normal Playwright output directories before archival was added. Some prior local PNG versions and early failure attachments were overwritten. Those originals were not recovered, and this report does **not** claim complete historical visual-evidence retention.

The runner now creates unique private before/after snapshots of `.local/qa`, `test-results` and `playwright-report`, refuses overwrite and treats preservation failure as a run failure. The final reporting run successfully exercised this behavior at `.local/test-evidence/1794641279379-bd0580f2-c939-4fe8-9290-2bf736e239d3/`. Current artifacts were also manually archived before the final full run. This protects subsequent evidence; it does not reconstruct lost earlier images. Existing database fixtures and original raw scan evidence were preserved.
