## Problems corrected

- Shared workspace used sales-only shortcuts and exposed owner settings navigation to staff without permission. Existing module destinations now use current actor permissions; server enforcement is unchanged.
- Report pages initially rendered thousands of optional entity options, delaying primary content on the accumulated QA dataset. Advanced controls mount on first expansion and remain mounted when closed. Date range/search stays visible; selections and actual export query were tested. No financial formula, backend filter/source limit or permission changed.
- Price editor silently stopped at 500 products. Read-only diagnosis: QWIK had 504 preceding products and was omitted. Bounded product/variant/SKU search, list-name search and preservation of existing targets/current assignments solve the demonstrated omission without unbounded queries.
- PO selector stopped at 1,000 suppliers. Read-only fixture creation-window diagnosis identified an omitted supplier with 1,039 preceding active suppliers. Search and draft supplier retention were verified through actual purchase/receiving. Search reloads unsaved forms; the UI says to search before editing/save first.
- Huge inventory tables now page 25 records. Original visible-cell formatting stays on the server; only formatted strings reach the pager. Full source totals/counts/CSV are unchanged. Horizontal regions retain keyboard focus and column headers have scope.
- Shared forms associate hints, expose busy state and announce failed saves as alerts. Sales screens show loading; proof errors can be corrected without weakening validation.
- Order/payment detail captions and customer next steps are clearer. Stale inventory “No stock is reserved” wording now describes reservation versus physical stock correctly.
- Loading fallback reserves a full viewport; diagnosed FOOTER shifts disappear in the final local production-build samples.

## Actual results and limitations

Full Playwright invocation: **309 passed/seven failed**, no skipped/flaky. Latest affected reruns: **28/28**, then complete inventory **37/37**; latest deduplicated **316 passes** (222 API/47 desktop/47 mobile). Original failures remain in private JSON/logs. Unit 46, production smoke 21, build, privileged dummy production-mode auth, TypeScript, lint and formatting passed. The unchanged strict integrity scan retains exit 1 for five expected synthetic order fixtures, zero unexpected findings and zero matches in development.

Final atlas: **368 states**, including admin price/PO entry forms, at 375×812, 390×844, 768×1024, 1366×768 in desktop/mobile-emulation contexts. Zero detected main-content axe violations, document overflow, unlabelled controls or short header anchors; 48 contrast checks remain incomplete. Some inline target heuristics require manual review. Native details and keyboard quantity/skip-link actions were exercised; there are no custom application modal/dialog flows to certify. File inputs were automated, not tested on physical OS pickers.

Reporting on the accumulated dataset can still take seconds and advanced choices become large after expansion. Source/lookup bounds and actual hosting capacity need representative acceptance. Raw IDs/free-text status filters and broad navigation remain in some areas; real staff training, screen readers, full keyboard-only tasks and physical-device testing are pending. No production IAM/access, real identity/enrollment, SMTP, TLS or backup recovery is certified by this UX work. No deployment performed.
